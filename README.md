# Kiko 的生日房间

生日：2026 年 11 月 14 日（农历十月初六）。

线上地址：https://yaqi777d.github.io/birthday/

这是当前发布版本的静态网站，使用 Three.js，适配电脑与手机。

## 本地预览

在本目录执行 `python -m http.server 8766 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8766/ 。

## 文件

- `index.html`、`style.css`、`app.js`：页面、样式和主场景交互。
- `city.js`、`jinmao.js`：江景及地标建筑。
- `room-decor.js`、`birthday-details.js`、`collectibles.js`：房间、桌面和布偶。
- `celebration.js`、`audio-track.js`、`music.json`：庆祝流程与音频。
- `gallery.js`、`bookshelf-quotes.js`：挂画图片与书架句子。
- `assets/`、根目录 SVG：网站使用的图片、音频、贺卡与手写字。
- `vendor/`：Three.js 和许可证。

GitHub Pages 从 main 分支根目录发布。Git 历史保留用于恢复；当前目录只维护最新版。
